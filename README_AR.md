# HUDHUD 0.34.2 — إصلاح بصري للمرحلة N02 فقط

هذه الحزمة تأتي بعد آخر رفع مؤكَّد 0.34.1، ولذلك تضم فقط الملفات المعدَّلة والجديدة منذ ذلك الرفع. لا ترفع 0.34.1 مرة أخرى.

التعديلات:
- تصغير الجار إلى حجم متناسب مع الطفل والبيوت على شاشة الهاتف والكمبيوتر.
- إضافة شخص جار يحمل أغراضاً عند موقفي إفساح الطريق وعرض المساعدة.
- إضافة صورة باب مفتوح لموقف احترام خصوصية الجار.
- إضافة توضيح بصري للسلام والاعتذار، وعناصر أكثر في مشهد المحافظة على نظافة الطريق.
- إضافة صورة جهاز الصوت عند موقف الضجيج فقط، دون تشغيل صوت أو موسيقى.
- إبقاء الخرائط والمراحل القديمة دون أي تغيير.

**مرحلة الوضوء M04 غير مشمولة، ولا يتغير أي ملف أو صورة لها.**
