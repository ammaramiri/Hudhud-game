# HUDHUD 0.34.6 — M11 + تعديلات M10/M09 السابقة

آخر رفع مؤكّد: 0.34.4. هذه حزمة تراكمية تجمع جميع ملفات 0.34.5 غير المؤكَّد رفعها مع إضافة M11.

## الرفع
1. فك ضغط ملف ZIP ثم ارفع محتوياته إلى جذر مستودع `ammaramiri/Hudhud-game` مع حفظ مسارات `assets/` و`js/` و`css/` و`docs/`.
2. استبدل الملفات ذات الأسماء المطابقة، ولا تحذف أصول اللعبة الأخرى.
3. بعد نجاح GitHub Pages اختبر `m11-stage-preview.html` و`m10-stage-preview.html` و`m09-stage-preview.html` واللعبة الرئيسية.

## المحتوى
- M11 — 14 موقفاً، بداية الصلاة بالقيام وتكبيرة الإحرام ومراجعة مكتوبة للفاتحة، دون صوتيات.
- «أتعلّم الصلاة» داخل قاعة الصلاة — سبع حلقات، M11 وحدها مفعّلة الآن، M23–M28 قيد الإعداد.
- استمرار إصلاح M09 لعلامة «المكان المناسب» وجميع إصلاحات M10 من 0.34.5.
- لا تغييرات في الوضوء M04 ولا في خريطة المسجد الرئيسية.
