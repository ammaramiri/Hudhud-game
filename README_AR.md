# HUDHUD v0.34.0 — حزمة واحدة كاملة بانتظار الرفع

## ماذا تحتوي؟
- Q13: تعديل مشهد مساعدة المحتاج والتصوير والخصوصية، وتصحيح المقاسات للموبايل.
- P08: التوسعة إلى 11 موقفاً وتحدٍّ إضافي، وتصحيح المقاسات.
- خريطة الحي الرئيسية: الصورة التي وافقت عليها، هي الخريطة نفسها مع إضافات صغيرة (صناديق بريد، معبر، مقاعد، محطة).
- ثلاث خرائط فرعية معتمدة ومقرّبة: `N1`, `N2`, `N4`، وساحة اللقاء N3 على الخريطة الرئيسية.
- مرحلة N02 «أراعي جاري» قابلة للعب في 10 مواقف متتابعة: إبعاد الدراجة، خفض جهاز الصوت، نقل كيس النفايات، السلام، إفساح الطريق، مراعاة الهدوء، المساعدة والاستئذان والاعتذار.
- **لا طبل ولا موسيقى ولا أناشيد ولا تشغيل صوتي.** الراديو مجرد صورة تُخفَّض/تُطفأ افتراضياً.
- رسومات WebP وأصول شخصية الجار دون ملامح وجه؛ شخصية اللاعب هي الشخصية الأصلية من اللعبة.
- إصلاح التكامل: ملف `js/progress.js` الذي تحمّله اللعبة بالفعل أصبح يحمل ملفات الحي الجديدة تلقائياً، فلا حاجة لتحرير index.html.

## مهم جداً
هذه حزمة **تراكمية**؛ لا ترفع 0.32.0 أو 0.32.1 أو 0.33.0 أو 0.33.1 معها، بل ارفع هذه وحدها بعد فك الضغط، مع الاحتفاظ بتوزيع المجلدات. لا تحذف ملفات اللعبة القديمة.

`assets/world/neighborhood-v3.webp` سيُستبدل بالرسم الذي وافقت عليه (نفس الخريطة مع أربع إضافات بصرية صغيرة). ينبغي السماح باستبدال الملف القديم، ولا يُعد تغييراً لهوية الحي.

## طريقة الرفع
فك الضغط، ثم انسخ الملفات والمجلدات إلى جذر مستودع GitHub `ammaramiri/Hudhud-game`. يجب الحفاظ على المسارات الأصلية واستبدال الملفات المطابقة. لا ترفع ملف ZIP نفسه إلى المستودع على أنه ملف اللعبة.
