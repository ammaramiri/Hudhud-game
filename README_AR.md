# HUDHUD 0.34.5 — تحديث M10 وتعديل M09

## رفع مرة واحدة

**آخر رفع مؤكد:** 0.34.4 (M09). هذه الحزمة تضم **فقط الملفات الجديدة والمتغيرة منذ ذلك الرفع**؛ لا تحتاج رفع حزمة 0.34.4 مجدداً.

1. فك ضغط `HUDHUD_PATCH_v0.34.5_M10_READY.zip`.
2. ارفع **المحتويات** إلى جذر مستودع `ammaramiri/Hudhud-game`، ولا ترفع مجلد ZIP نفسه؛ احتفظ ببنية `js/` و`css/` و`assets/m10/` و`docs/`.
3. استبدل الملفات المطابقة، ولا تحذف الملفات القديمة الأخرى.
4. بعد نجاح نشر GitHub Pages افتح:
   - https://ammaramiri.github.io/Hudhud-game/m10-stage-preview.html
   - https://ammaramiri.github.io/Hudhud-game/m09-stage-preview.html
   - https://ammaramiri.github.io/Hudhud-game/

## ما تغير

- إضافة M10 كاملة، 14 موقفاً في ثلاث لغات وحفظ الإنجاز.
- صورة سجادة جديدة WebP شفافة مع إعادة استعمال خلفية المحراب الموجودة في M09 نفسها، دون تغيير جدار القاعة أو الخريطة.
- تفعيل M10 داخل قاعة الصلاة نفسها وإظهار M09 وM10 باللون الأخضر الداكن وعلامة الإنجاز عند الانتهاء.
- تحديث `progress.js` لتحميل M10 وإضافة `m10` إلى سجل الإنجاز.
- **إصلاح M09 الذي طلبته**: اسم المكان المناسب أعلى دائرة الهدف لكي لا يحجب الرف والأغراض؛ لم نغير موضع الهدف الحقيقي.
- لم يتغير `M04` الوضوء أو أي صورة فيه.

اختبر مسار M10 كاملاً على الهاتف، مع اختبار العرض على الكمبيوتر وحفظ الإنجاز. روابط التجربة أعلاه تعمل بعد رفع الملفات وإتمام النشر؛ لا تُعد تأكيداً بأن المستخدم رفعها.
