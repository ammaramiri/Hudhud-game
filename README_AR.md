# HUDHUD — حزمة الرفع التراكمية 0.34.4 — مرحلة M09

## ما الجديد؟
- مرحلة `M09 — أستعد للصلاة` **قابلة للعب** في 14 مشهداً تفاعلياً مترابطاً.
- صورة قاعة الصلاة التفصيلية وثمانية أصول WebP شفافة، مع استخدام أفاتار الطفل/الطفلة الموجود أصلاً.
- زر «قاعة الصلاة» داخل خريطة المسجد الأصلية يدخل القاعة الجديدة (دون استبدال خريطة المسجد).
- ستة مداخل قاعة الصلاة: M09 جاهز بلون داكن وعلامة صح بعد الإنجاز، M10–M14 قيد الإعداد، M11 يعرض مسار «أتعلّم الصلاة» المخطط.
- تكامل سجل الإنجاز: أصبح المجموع التخطيطي للمسجد 28 مرحلة، وهي تشمل M23–M28 المخطط لها.

## الملفات المتراكمة
هذه الحزمة تضم **جميع ملفات التعديل غير المؤكد رفعها** بعد آخر رفع مؤكد للإصدار 0.34.1، بما فيها إصلاحات N02 من 0.34.2 و0.34.3؛ لا ترفع حزمتيهما منفصلتين. لا تحتوي أي ملف يعدّل مرحلة الوضوء M04.

## الرفع
فك ZIP وارفع **محتوياته** إلى جذر المستودع `ammaramiri/Hudhud-game` مع الحفاظ على أسماء المجلدات. استبدل الملفات المتطابقة فقط، ولا تحذف الملفات الأخرى.
